# Student CRUD Application

A Java web application for managing student records using CRUD operations.

## Features

- Add new student
- View all students
- Update student details
- Delete student
- MySQL database connectivity

## Technologies Used

- Java
- JSP
- Servlets
- MySQL
- Apache Tomcat
- HTML/CSS
- Eclipse IDE

## Project Structure

- `src/main/java/com/student` - Java Servlets and database code
- `WebContent` - JSP pages and web resources
- `.gitignore` - Files excluded from Git

## Database

This project uses MySQL to store student information.

Before running the application:
1. Create the required MySQL database.
2. Configure the database connection in the project.
3. Deploy the project on Apache Tomcat.

## How to Run

1. Import the project into Eclipse.
2. Configure Apache Tomcat.
3. Configure MySQL.
4. Start Tomcat.
5. Open the application in your browser.
